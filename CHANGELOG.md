# Changelog

## 1.0.0 - 2026-10-15

- Added ten independent nuclear astrophysics calculation interfaces and fifteen views.
- Added classical energy PDF, S extraction, Gamow location/full1/e width, adaptive thermal rate, event rate, depletion timescale, isolated resonance, logarithmic sensitivity and explicit local heating.
- Added five selected reactions/eight attributed data-model records, pinned source hashes and checksum-guarded processing.
- Added bilingual controls/descriptions and primary warnings, RTL, theme persistence, responsive styles, interactive SVG and matching calculation snapshots for PDF/CSV/PNG.
- Added source-separated uncertainty policy, numerical diagnostics, model gates, missing-data handling and explicit absence of deposited energy by default.
- Added scientific/data/report/server-render tests, browser scenarios, manual-only Pages deployment, production and self-contained builds.
- Fixed endpoint roundoff refusal without enabling cross-section extrapolation, and very-low-temperature normalization missing a thermal peak across an excessively wide numerical interval.
- Embedded DejaVu Sans in PDF exports and prevented orphan section headings after visual inspection.
- Browser verification remains skipped because Chromium was unavailable; see the actual executed report.
