## Particular distinctions

03 and04 both require a nonresonant kernel but ask for location versus curvature. A narrow peak at one energy can have a different width if local curvature changes; the Gaussian treatment introduces an approximation beyond locating the maximum. Returning E0 and Delta in the window view does not create an eleventh calculation.

05 integrates an energy-dependent function over a declared domain; it exposes interpolation, tail coverage and numerical convergence.08 instead requires measured resonance strength and width and evaluates an isolated on-resonance approximation whose applicability can fail even when a generic integral is mathematically possible. It is not presented as another total rate evaluation.

06,07 and10 use a coefficient for different primary observables: event counting, depletion response and local energy deposition. Their physics assumptions and failure modes are separately represented. Standalone input rearrangements, unit converters, reaction selectors and general full-analysis summaries are supporting utilities, not counted as additional scientific calculations.
